Arhopala ID

An interactive app for identifying Malaysian Oakblue (Arhopala) butterflies.

C&P+ (recommended)

C&P+ follows the original numbered dichotomous key but adds Cannot determine options for couplets requiring the upperside, forewing spaces 2–3, or genital characters — so the key can continue from underside-only photographs. Candidates are ranked in real time as you answer each couplet.

At branching points where a skip would conceal one group entirely, Cannot determine opens into two labelled paths — follow whichever description matches your specimen, or try both if you are unsure.

C&P Key

The C&P Key presents the original Corbet & Pendlebury numbered-lead key strictly — choose Yes or No at each couplet. Each step is labelled with its C&P key number (e.g. Key 8), and a breadcrumb trail lets you tap back to any earlier couplet. Best suited to spread specimens or photographs where the upperside and forewing base are clearly visible.

How to use it

  1. Open C&P+ and work through couplets one by one, choosing the statement that best matches your specimen.
  2. For anything you cannot observe, select Cannot determine — candidates are re-ranked from the steps you could answer, and the key continues.
  3. At a dual-path branch, both paths open in parallel; follow the one whose description matches, or explore both.
  4. A result card may identify a single species, or flag a closely similar pair requiring additional observation.
  5. Tap any key number in the breadcrumb to step back, or Start Over to reset.

Coverage

Scope: Peninsular Malaysia only. The key is based on identification literature covering Arhopala species recorded from the Malay Peninsula. Bornean endemic species are not covered. Characters used are primarily from the underside wing pattern and morphology, supplemented by geography where Peninsular and Bornean ranges overlap.

⚠ Some species pairs cannot be reliably distinguished without observing the upperside or performing genitalia dissection; the key will flag these cases explicitly.

Species Search

Use Species Search to browse or search all taxa covered by this key. Each species page shows identification characters, reference photos from iNaturalist, the numbered route through the C&P key, and an underside-only path summary — the couplets reachable from a typical field photograph.

Visual Guide

The Visual Guide explains the wing terminology used throughout the key — spaces, postdiscal spots, end-cell bar, and other characters — with labelled diagrams. Consult it before starting if you are unfamiliar with the notation, or tap the guide links inside individual couplets to jump straight to the relevant diagram.

Data & sources

The identification key is based on published morphological literature for Malaysian Arhopala.

Open source & contributions

Arhopala ID is an open source project. The source code, identification data, and key text are all publicly available on GitHub. Contributions are welcome — whether that is correcting an identification, adding a missing species, improving the key text, or extending coverage to a new region. See the repository's REPLICATING.md guide for how to adapt the project for another genus or region.
